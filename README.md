# ICGroup Admin

Админ-панель проекта ICGroup.  
Здесь будет разрабатываться внутренний интерфейс для управления контентом и пользователями.

## Технологии

- Vite
- React
- TypeScript
- ESLint + Prettier
- Husky (pre-commit)
- Vitest + React Testing Library

## Назначение

Админка будет включать:

- авторизацию и ролевую модель
- управление материалами
- редактор контента
- интерфейсы для CRUD-операций

## Статус

Проект находится на этапе инициализации.
